# UI 重构方向：ON AIR 播出单

> 本文是一次**界面重构**的方向与规范，不是功能改动。
> 实现时以本文的 tokens 与组件为准；任何"这里看起来空，加个装饰"的想法都应先回到第 11 节的验收清单。
>
> 本文是 0.4.16 那次界面重构的方向与规范（公开征集阶段已结束，界面按此定稿）：原生窗口外壳、不手绘边框/圆角/阴影，层级靠留白、分组与字号。
>
> 设计方法参照 Anthropic 的 `frontend-design` skill（先定 brief → 出 token 与原则 → 对照"AI 默认长相"自查 → 再落地）。

---

## 1. 先定 brief（没人给 brief 就自己定一个）

**MuSync 是什么**：一个常驻托盘的小工具，把"你此刻在听什么 / 在用哪个程序"变成 **Steam 上的一行 ≤128 字节的状态文本**。

**由此推出的三条硬事实**（决定了界面该长什么样）：

1. **真正的产出是一行字**，不是封面、不是卡片。界面若不能让人看清"那行字是什么"，就是在装饰。
2. **看的时间极短**：随音乐被顺带瞟一眼，通常几百毫秒。层级必须一次到位，不能靠阅读顺序解锁。
3. **它是"旁路"工具**：不抢焦点、不弹窗、藏在托盘里。看起来越像"播控台上的指示器"越对，越像"音乐播放器主界面"越错。

**目标用户**：本机同时开着音乐软件与 Steam 的人；对"状态被顶掉/显示错歌"极度敏感。

---

## 2. 视觉母题：播出单（Cue Sheet）

选"录音棚/电台播控台"作为材质来源，而不是"音乐播放器"：

- **纸与墨**：浅色纸面 + 纯黑字，量尺用极细的线。不做暗色霓虹（同类工具全在暗色 + 荧光色，那是默认值）。
- **两把尺子**：一根量**时间**（播放进度），一根量**字节**（Steam 的 128 字节限制）。字节尺是本产品独有的真实约束，也是整个界面唯一"别人没有"的结构件。
- **一枚灯**：ON AIR 红点，只表示"正在往 Steam 推"。全界面只有这一个强调色。
- **封面是唯一的彩色**：封面本身颜色杂乱，界面其余部分必须中性，否则会和封面抢注意力。

一句话：**主窗口是一块播出牌，设置是一本播出单，编辑器是一张脚本。**

## 3. Tokens

### 3.1 颜色

| 名称 | 值 | 用途 |
|---|---|---|
| `paper` | `#EFEDE6` | 全局底色（冷调纸白；不是奶油色 `#F4F1EA`） |
| `paper-inset` | `#E6E3D9` | 输入框、表格选中行等"凹陷"面 |
| `ink` | `#000000` | 主文字、主按钮底（**纯黑**，不用 #111/#0B0B0B 之类的"假黑"） |
| `ink-muted` | `#6B6B63` | 次要文字、单位、说明 |
| `rule` | `#C9C6BA` | **只用于计量与控件描边**（尺子刻度、输入框边框、表格分隔） |
| `onair` | `#D22B1F` | 唯一强调色：正在同步 / 超预算 / 错误 |
| `idle` | `#9A9A90` | 待机点、禁用态文字 |
| `warn` | `#A86A12` | 仅用于"暂停/需要确认"这类中间态 |

规则：**同一屏内出现两种强调色即视为 bug**。绿色不出现（"正常"由墨色表达，不用红绿灯套路）。

### 3.2 字体（2026-11-04 修订：不内置字体，改用系统字体栈）

| 角色 | 字体 | 字号 / 行高 | 用途 |
|---|---|---|---|
| 展示 | Segoe UI Semibold | 26 / 30 | 曲名、页面主标题 |
| 标题 | Segoe UI Semibold | 16 / 22 | 分区标题（句首大写，不用全大写） |
| 正文 | Segoe UI | 12.5 / 18 | 标签、说明 |
| 数据 | Consolas | 12 / 16 | **Steam 状态行**、时间、字节数、端口、令牌、URL |
| 微数据 | Consolas | 11 / 14 | 单位、表格表头 |

规则：

- 两种字体就够：无衬线做"人读的"，等宽做"机器读的"。**状态行天然是等宽字符串**，宽度是真实约束，用等宽不是风格而是事实。
- 层级差 ≥3 倍（26 vs 12），不用 400↔600 这种小差。
- 数字一律等宽（Consolas 天然满足），避免跳动。
- 正文行长 < 80 字符；许可证等长文本面板放宽到 68–72 字符。
- 用户可在 **设置 → 显示 → 外观字体** 覆盖字体族与字号；覆盖只作用于主界面文字，不改主题 token。

**为什么不用最初设计的 Archivo / IBM Plex Mono（原方案已废弃）：**

1. 主界面的控件位置是按当前字体度量手工调过的（含 144 DPI 下的实测），换字体族会让**每一处文本宽度变化**，
   需要连带重调所有手工坐标与 `AutoSize` 边界 —— 属于"改一个字体会牵出一串布局回归"的改动。
2. 中文字形覆盖：Archivo / Plex Mono 都不含中日韩字形，中文界面下 WinForms 会按字形回退到系统 CJK 字体，
   于是**中英混排出现两种字重与两种宽度**，反而比统一用系统字体更乱。
3. 收益只有"看起来更特别"，代价是发版前的布局风险 —— 按"先不出 bug"的优先级，放弃。

如果以后确实要换字体族，**前置条件**是：先在 100/125/150/200% DPI 下量一遍所有 `AutoSize=false` 控件与手工坐标的边界，
并接受一次全量布局复核；不要只换字体然后指望 `PerformAutoScale` 兜住。

### 3.3 间距与栅格

- 基础单位 **4**；只用 4 / 8 / 12 / 16 / 24 / 32。
- 单列版心，左右留白 16；分区之间 24；分区内元素之间 8。
- **圆角恒为 0**；**不使用阴影**（层次靠留白、`rule` 与 `paper-inset`）。
- 控件高度：输入/按钮/行 **32**；紧凑表格行 **28**；状态点 **8**。

## 4. 组件规范

### 4.1 状态点 `StatusDot`

```
● 8px 实心圆 + 右侧标签（正文体，句首大写）
onair 红 → "ON AIR"（唯一允许大写的文本，表示状态而非分类）
warn 琥珀 → "已暂停"（玩游戏时暂停 / 手动暂停）
idle 灰   → "待机"（未登录 / 未同步 / 无内容）
```

### 4.2 量尺 `Measure`

两把尺子共用同一实现，**只量真实数值**：

```
▏███████████████░░░░░░▏ 87 / 128 B      ← 字节预算（超出的部分在末端画红段 + 硬停止标记）
▏████████████░░░░░░░░░▏ 2:04 / 5:03     ← 时间进度
```

- 刻度：四分之一处 3px 短刻线（`rule`），无数字。
- 填充：`ink`；超预算段：`onair`。
- 右侧数值：数据字体，右对齐，单位用小一号。
- 无动画填充（播放中的进度靠 tick 更新，不做平滑插值）。

### 4.3 状态预览行 `StatusPreview`

**整个产品的主角。** 等宽字体，展示"此刻 Steam 上真实显示的那行字"。

```
▶ 正在听 Mr. "Broken Heart" — 米津玄師
```

- 前缀 `▶`/`⏸` 表示播放状态，颜色跟随 `StatusDot`。
- 截断位置画 `▏`（细竖线），让人看到"到这里就没了"。
- 超 128 字节：末段文字变 `onair` 红，并在末尾显示 `+7 B`。
- 点击 = 复制整行；复制后 1.2 秒内显示 `已复制`（原位替换数值区，不弹 toast）。

### 4.4 行 `Row`

```
播放器                                    QQ音乐
```

- 高度 32，左标签 `ink-muted` 12.5，右值 `ink` 12.5（技术值用 mono）。
- 可交互行才画 1px `rule` 下边线；纯展示行不画线。

### 4.5 输入 `Field`

- `paper-inset` 底 + 1px `rule` 描边 + 0 圆角 + 高 32。
- 焦点：描边改 `ink`，并在下方加 2px `ink` 下划线（不改变布局尺寸）。
- 值用 mono（端口、URL、令牌、路径）或正文（名称、显示格式）。
- 错误：描边 `onair` + 下方 1 行说明（说清怎么改）。

### 4.6 按钮 `Button`

| 类型 | 样式 |
|---|---|
| 主 | `ink` 实底 + `paper` 文字，高 32，左右内边距 16 |
| 次 | 透明底 + 1px `ink` 描边 |
| 危险 | 透明底 + 1px `onair` 描边 + `onair` 文字 |
| 文本 | 无边框，仅下划线 hover |

- 禁用：文字 `idle`，边框 `rule`，不做透明度（纸面上"淡"会显得脏）。
- 一个界面最多 **1 个主按钮**。

### 4.7 开关 `Stamp`（替代 iOS pill）

```
[开]      ← ink 实底 + paper 文字
[关]      ← 透明 + rule 描边 + ink-muted 文字
```

理由：开关是"状态印章"，与播出单语言一致；胶囊滑块的视觉语言属于移动端，在桌面播控面板里是外来物。

### 4.8 分区 `Section`

```
分区标题（16px，句首大写）
一句话说明它为什么存在（12.5，ink-muted）
────────────────────────────  （可选，仅当分区内含可滚动列表）
内容
```

不画容器边框、不加底色。

### 4.9 表格 `Table`（程序列表 / 数据源列表）

- 行高 28，行间 1px `rule`；表头 mono 11 `ink-muted`（小写，不用全大写）。
- 选中行：`paper-inset` 底 + 左侧 2px `ink` 竖条。
- 无斑马纹、无交替底色。

### 4.10 对话框壳 `Dialog`

- 保留系统标题栏（不做无边框窗口：拖拽/贴边/DPI 的坑远大于收益）。
- 内容区 `paper`，四周 16 内边距；底部动作栏右对齐，主按钮在右。
- 取消用次按钮或右上关闭，不额外放"取消"主按钮。

### 4.11 空态 / 错误态 / 加载态

- 空：一行说明 + 一个主按钮（"添加数据源"/"去登录"）。
- 错误：错因 + 怎么修，两行；不道歉、不用感叹号。
- 加载：状态点转 `idle` + 文字"正在读取"，**不做骨架屏/spinner**（本项目窗口小、等待短，动画反而像卡住）。

### 4.12 托盘

- 提示文本 = `StatusPreview` 的同一行（一致性靠复用同一份字符串生成函数）。
- 菜单保持系统原生样式，只清理文案（动词开头、"显示主窗口"/"暂停同步"/"退出"）。

## 5. 页面骨架

### 5.1 主窗口（约 420 × 168，可缩放至 520 × 200）

```
┌──────────────────────────────────────────────────┐
│ ● ON AIR                        steam ▸ 好友可见  │
│ ┌────┐ Mr. "Broken Heart"                        │
│ │ 封 │ ♪ 4:12 / 5:03                    QQ音乐   │
│ └────┘                                           │
│ ▶ 正在听 Mr. "Broken Heart" — 米津玄師            │
│   ▏███████████████░░░░░░▏ 87 / 128 B             │
│   ▏████████████░░░░░░░░░▏ 2:04 / 5:03            │
│                          设置   暂停   复制诊断  │  ← 文本按钮，右下
└──────────────────────────────────────────────────┘
```

- 封面 56×56，无圆角无边框；没有封面时用播放器图标，仍不画框。
- "steam ▸ 好友可见"是**目的地**，不是按钮；离线时变 `idle` 并显示"未连接"。
- 程序同步（没有音乐时）：封面位换成程序图标，状态预览显示程序状态行，字节尺照常。

### 5.2 设置（720 × 560，左侧栏 + 内容区）

```
┌───────────┬──────────────────────────────────────┐
│ 设置       │ 常规                                  │
│           │ 启动与关闭的行为                      │
│ 常规   ●   │ 开机自启                        [关]  │
│ 同步       │ 启动时最小化到托盘              [开]  │
│ 显示       │ 关闭窗口时最小化到托盘          [开]  │
│ 程序       │ ────────────────────────────────────  │
│ 诊断       │ 语言                                  │
│ 关于       │ 界面语言              中文 ▾          │
│           │                        [保存更改]     │
└───────────┴──────────────────────────────────────┘
```

- 左栏 160px，页面名正文体；当前页左侧 2px `ink` 竖条（不用胶囊/底色块）。
- 左栏底部显示版本号（mono 11，`ink-muted`）。
- 每页只放"同类"设置，页内用 `Section` 分组；保存按钮固定在右上下角（每页一个）。
- 六个页面：**常规 / 同步 / 显示 / 程序 / 诊断 / 关于**（沿用现有信息架构，不重排功能）。

### 5.3 格式积木编辑器（640 × 460）

```
┌────────────────────────────────────────────────────┐
│ 状态模板                                            │
│ ┌──────────────────────────┬─────────────────────┐ │
│ │ ▶ 正在听 {song} — {artist} │ 预览                │ │
│ │ {progress} {bar}          │ ▶ 正在听 晴天 — 周杰伦│ │
│ │                           │ ▏██████░░░▏ 87/128B │ │
│ └──────────────────────────┴─────────────────────┘ │
│ 可用积木  {app} {song} {artist} {progress} {bar}     │
│           {time} {sep}  + 自定义数据源名             │
│                                    [取消] [保存]     │
└────────────────────────────────────────────────────┘
```

- 编辑区与预览区 1:1 并排；编辑区 mono，预览区**与主窗口同一渲染**。
- 积木以 mono 芯片列出，点一下插入光标处（不做拖拽）。
- 预览下方同样带字节尺——改模板时立刻看到预算消耗。

### 5.4 Steam 登录（360 × 近内容高度）

```
┌─────────────────────────────────┐
│ 登录 Steam                       │
│ 账号或令牌会在本机加密保存        │
│ 用户名      [                ]   │
│ 密码        [                ]   │
│ 记住我                          │
│             [关]                 │
│ 错误：密码错误，请重新输入        │  ← 仅出错时出现
│                  [取消] [登录]   │
└─────────────────────────────────┘
```

- 验证码字段按需出现（`Field` + 说明"查看手机令牌/邮箱"）。
- 登录中：主按钮文字变"正在登录"，禁用，其余保持可读（不弹遮罩）。

### 5.5 更新窗口（520 × 420）

- 顶部：`v0.4.15`（mono）+ 发布时间（mono 11）。
- 正文：版本说明，正文体，行长 ≤72 字符。
- 下载：**复用字节尺**（`▏████░░▏ 18.2 / 60.5 MB`）+ 速度（mono 11）。
- 未签名提示：`warn` 一行 + "继续安装"为次按钮，不默认聚焦。
- 底部：`[在浏览器中打开]`（次）+ `[安装并重启]`（主）。

### 5.6 许可证 / 关于

- 长文本：单列，行长 68–72 字符，标题用 `Section` 样式。
- 关于页：版本、构建提交（mono）、开源致谢链接、"复制诊断信息"。

### 5.7 首次启动 / 空态

- 主窗口没有内容时：`● 待机` + "切到已启用的程序或开始播放音乐后，这里会显示 Steam 上的状态"（一行），右下仍保留三个文本按钮。

## 6. 文案规范

- 主动语态、动词开头：按钮是"保存更改"，成功提示是"已保存"（同一个动作全程同名）。
- 用用户的语言命名："数据源""积木""Steam 状态"，不用内部术语（"DynamicBlockResolver"之类只出现在诊断里）。
- 错误必须回答两件事：**发生了什么、怎么修**。例："连不上 Steam（网络超时）。检查网络后点重试，或稍后自动重试。"
- 空态是邀请，不是安慰："还没有数据源" → "添加数据源后可把心率、天气等显示在状态里"。
- 不用"！"、不用"抱歉"、不用"请稍候"（等待时直接说在做什么）。
- 一切全大写的文本禁止，除 `ON AIR`（理由见 4.1）。

---

## 7. 动效规范（只有三处）

| 场景 | 动效 | 时长 |
|---|---|---|
| 状态点从待机变为 ON AIR | 红点不透明度 0→1 呼吸一次后停住 | 600ms，只播一次 |
| 强调色变化（红↔琥珀↔灰） | 颜色线性过渡 | 200ms |
| 设置页切换 | 直接替换（不做滑入） | 0ms |

- 其余一律无动画：不做逐块入场、不做卡片 hover、不做进度平滑插值。
- 尊重系统"减少动画"设置：开启时全部改为瞬时切换（呼吸灯也取消）。

---

## 8. 可访问性与 DPI

- 焦点必须可见：`ink` 2px 下划线或 1px 外框，对比度 ≥3:1；Tab 顺序按视觉顺序。
- 对比度：`ink` on `paper` ≈ 18:1；`ink-muted` on `paper` ≈ 5.3:1（正文合格，不用于小号关键信息）。
- DPI：`PerMonitorV2`；100/125/150/200% 四档都要截图核对；所有尺寸用 DIP，绘制时乘 DPI。
- 文字最小 11px（微数据），关键信息不小于 12.5px。

## 9. WinForms 落地方式

| 需要 | 做法 |
|---|---|
| Tokens | 新增 `Utils/Theme.cs`：颜色/字体/间距常量 + `Font` 缓存（避免每次 new Font 泄漏 GDI 句柄） |
| 自绘 | `StatusDot`、`Measure`、`StatusPreview`、`Stamp`、`Table` = `Control` 子类，`OnPaint` + `SetStyle(DoubleBuffered)` |
| 字体 | 系统字体栈（Segoe UI / Consolas）；不内置字体文件，避免换族带来的全局布局位移 |
| 现有控件 | `TextBox`/`ComboBox` 保留原生（可绘制性差），只统一字体、颜色、高度；`CheckBox` 换成 `Stamp` |
| 标题栏 | 保留系统标题栏；不做无边框窗口 |
| 表格 | `DataGridView` 关掉所有边框/斑马纹/行头，行高 28，选中色 `paper-inset`；或直接自绘列表 |
