# MuSync 浏览器桥（扩展）

把浏览器里正在播放的媒体（视频 / 音频）上报给 MuSync。

**为什么需要它**：MuSync 默认通过 Windows 系统媒体控件（SMTC）读取浏览器播放状态。但 SMTC 只能看到"网页主动发布了媒体会话"的情况——不少站点（尤其国内小站、网盘播放器、直播页）根本不发布，系统里连会话都没有，任何按 SMTC 读取的程序都拿不到。这个扩展直接在页面里读 `navigator.mediaSession` 和 `<video>` 元素，因此不受该限制。

## 安装（Edge / Chrome，开发者模式加载）

1. 打开 `edge://extensions`（Chrome 是 `chrome://extensions`）
2. 打开右下角 **「开发人员模式」**
3. 点 **「加载解压缩的扩展」**，选择本目录（`extension/`）
4. 装好后图标栏会出现 "MuSync Browser Bridge"（可以固定到工具栏，方便确认）

> 不需要发布到商店；文件改了之后在扩展页点一下「重新加载」即可。

## 在 MuSync 里打开

1. MuSync → 设置 → **同步** → 勾选「**浏览器扩展增强（实验性）**」
2. 端口保持默认 **47564**（与 `background.js` 里的 `MUSYNC_PORT` 一致；改端口两边都要改）
3. 右边会显示状态：`已监听 127.0.0.1:47564，等待扩展上报…` → 播放后变成 `收到：<标题>`

## 验证

- 浏览器播放任意媒体 → MuSync 状态应在 1~2 秒内变化
- 排查：浏览器里直接访问 <http://127.0.0.1:47564/status>，应返回类似
  `{"listening":true,"port":47564,"data":{"title":"...","playing":true,"ageSeconds":0.4}}`
- MuSync 日志里会有 `[浏览器扩展] 已监听 …` 和 `[浏览器扩展] 收到：…`

## 边界与已知限制

- **只发到本机**（`127.0.0.1`），扩展不联网、不上报任何数据到外部。
- 同一时刻多个标签页都在播放时，**后上报的覆盖先上报的**（MuSync 只保留最近一条）。
- 暂停后仍会继续上报（保持"暂停"状态可见）；视频结束后停止上报，MuSync 约 5 秒后自动清除。
- 扩展需要「读取所有网站数据」的权限（`<all_urls>` 的 content script），否则无法在任意站点读取播放状态。
- MuSync 没开或端口不对时，扩展会静默失败，不影响网页本身。
